# Data Structures and Algorithms (DSA) College Assignment Repository

Welcome to my Data Structures and Algorithms (DSA) coursework repository! This repository contains all my programming assignments, lab exercises, and practical implementations for my college coursework.

---

## 📂 Repository Structure

The repository is organized by topics to keep the code clean and easy to navigate:

* `Arrays/` - Array manipulation, searching, sorting, and algorithmic problems.
* `Linked Lists/` - Singly, doubly, and circular linked list implementations and operations.
* `Stacks & Queues/` - Stack and queue applications, expression evaluation, and queue implementations.
* `Trees & Graphs/` - Binary Trees, Binary Search Trees (BST), graph representations, and traversal algorithms (BFS, DFS).
* `Sorting & Searching/` - Implementation of standard sorting and searching techniques.
* `Recursion & Backtracking/` - Classic recursive problems and backtracking algorithms.
